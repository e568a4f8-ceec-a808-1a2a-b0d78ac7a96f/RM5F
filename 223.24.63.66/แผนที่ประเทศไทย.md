<!-- wp:paragraph -->
<p><br /><a href="https://wiki.openstreetmap.org/wiki/OpenStreetMap" class="mw-redirect">OpenStreetMap</a>&nbsp;represents&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Features">physical features on the ground</a>&nbsp;(e.g., roads or buildings) using&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Tags">tags</a>&nbsp;attached to its basic data structures (its&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Nodes" class="mw-redirect">nodes</a>,&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Ways" class="mw-redirect">ways</a>, and&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Relations" class="mw-redirect">relations</a>). Each tag describes a geographic attribute of the feature being shown by that specific node, way or relation.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>OpenStreetMap's&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Tags">free tagging system</a>&nbsp;allows the map to include an unlimited number of attributes describing each feature. The community agrees on certain key and value combinations for the most commonly used&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Feature_tag" class="mw-redirect">feature tags</a>, which act as informal standards. However, users can create new tags to improve the style of the map or to support analyses that rely on previously unmapped attributes of the features. Short descriptions of tags that relate to particular topics or interests can be found using the&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Category:Features">feature pages</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Most features can be described using only a small number of tags, such as a path with a classification tag such as&nbsp;<code class="mw-content-ltr"><bdi><a href="https://wiki.openstreetmap.org/wiki/Key:highway">highway</a></bdi>=<a href="https://wiki.openstreetmap.org/wiki/Tag:highway%3Dfootway"><bdi>footway</bdi></a></code>, and perhaps also a name using&nbsp;<code class="mw-content-ltr"><bdi><a href="https://wiki.openstreetmap.org/wiki/Key:name">name</a></bdi>=*</code>. But, since this is a worldwide, inclusive map, there can be many different feature types in OpenStreetMap, almost all of them described by tags.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>There are&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Category:Proposed_features">proposed changes to existing tags</a>,&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Category:Inactive_features">inactive features</a>&nbsp;and&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Deprecated_features">deprecated features</a>. If you do not find a suitable tag in this list then feel free to make something suitable up as long as the&nbsp;<a href="https://wiki.openstreetmap.org/wiki/Verifiability">tag values will be verifiable</a>. Over time, you may find that the tag name is changed to fit with some wider consensus. However, many good tags were used first and documented later. For the latest updates of tagging schemes see&nbsp;<em><a href="https://wiki.openstreetmap.org/wiki/Changelog">Changelog</a></em>.</p>
<!-- /wp:paragraph -->
